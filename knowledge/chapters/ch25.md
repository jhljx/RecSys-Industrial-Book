# 第 25 章阅读地图：多任务融合

## 章节主线

从固定公式与全局寻参出发，逐步转向上下文权重、排序学习和面向多目标冲突的融合模型。多任务预测提供各目标的估计值；本章关注如何把这些估计值转为统一的排序决策。

| 节 | PDF 页 | 核心问题 | 工程检查点 |
|---|---:|---|---|
| 25.1 多任务融合概述 | 1–2 | 融合与上游多任务预测的职责如何区分？ | 核对各目标预测值的尺度、校准和业务含义。 |
| 25.2 人工设计的融合方法 | 2–4 | 值、序和值序混合分别保留什么信息？ | 比较分布漂移、补偿关系及额外排序成本。 |
| 25.3 自动化参数寻优 | 4–6 | 固定公式的参数怎样在实验预算内搜索？ | 固定评估口径，记录噪声、约束和线上护栏。 |
| 25.4 学习式融合权重建模 | 6–9 | 全局参数何时需要变为上下文权重？ | 检查权重范围、特征可用性与分群稳定性。 |
| 25.5 Learn to Rank 模型融合 | 9–11 | 如何用真实反馈训练统一排序分数？ | 保持请求分组、曝光归因和训练服务预测一致。 |
| 25.6 端到端多目标融合模型 | 11–29 | IntEL、UMRE、EMER、HarmonRank分别解决什么问题？ | 分别验证意图、单调性、请求级监督及排序目标一致性。 |
| 25.7 工业实践与发展方向 | 29–31 | 如何协调业务目标和线上开销？ | 分目标效果、P99、实验护栏与回滚线共同评估。 |
| 25.8 本章小结 | 31 | 如何选择融合方法？ | 从数据、预算和监督条件倒推复杂度。 |
| 25.9 参考文献 | 32 | 如何核对代表方法出处？ | 以论文原文和本章 PDF 核验方法边界。 |

## 学习产出

在同一请求级候选集上比较固定值融合、Rank融合、全局寻参、动态权重与LTR：给出标签窗口、分目标排序指标、线上成本和回退策略，再说明四篇代表方法分别增加了什么建模能力。
