## 定义
生成语义 ID 到可服务物品检索，是将生成模型输出的离散标识解析并映射为实际库存物品的环节。

## 核心判断
生成 token 序列不是最终可展示物品；必须将有效语义 ID 映射回在库物品，并处理多对一重复与查不到物品等异常，才能与传统召回比较。

## 工程检查
记录语义 ID 有效命中率、映射成功率、去重后候选数、物品状态和码本／映射版本；规定空结果与过期内容的兜底路径。

## 本书依据
《第九章-生成式推荐模块.pdf》，PDF 第 12–14 页（9.5 物品 ID 检索及异常情况）。

## 扩展说明
将生成器与映射索引按相同版本灰度，避免迁移期间合法 token 被错误判为无效。
