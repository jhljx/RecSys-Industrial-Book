数据漂移检测：PSI、KL 与 Label Drift（第15章 §15.6.5） 漂移可以分几层： - 特征分布漂移：P_train(X) ≠ P_online(X) - 用户/物品结构漂移：时间段不同，人群与内容池的构成变了 - 场景漂移：节假日、大促、热点带来的短期流量突变 - Label 漂移：CTR、长播率等指标本身的均值/分布变了 脚本构造三段时间的数据： 训练期 0–30 天 → 稳定期 30–60 天 → 漂移期 60–90 天 在漂移期分别注入两种变化： A) 平滑漂移：用户活跃度整体上升（新用户涌入） B) 结构漂移：某类目供给大幅增加，同时 Label 的基线概率上升 然后计算： PSI = Σ (p_online − p_train) · ln(p_online / p_train) 分箱用训练集分位数 KL = Σ
