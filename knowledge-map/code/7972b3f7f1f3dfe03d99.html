Weighted LR 与 MSE 回归：两条路径都指向 E[t|x]，但梯度行为不同（第23章 §23.2） 正文的两个论点，本脚本都用可跑的对照实验验证： 1) WLR 把一次曝光展开成「负样本（权重 1）+ 正样本（权重 t）」， 损失为 L = −t·log p − log(1−p)；最优解满足 p/(1−p) = E[t|x]， 所以推理时用 e^z 即可反解出观看时长。 2) WLR 与 MSE 在最优解上都逼近 E[t|x]，但 · MSE 的梯度是 2(t̂ − t)，长时长样本的误差被平方放大； · WLR 的梯度是 t·σ(−z) − σ(z)，长时长以权重形式进入分类损失， 可以用 min(t, T_max) 或 log(1+t) 截断长尾。 这里还顺带展示：权重一改，反解的目标就不再是 E[t]，而是 E[w(t)]。
