对应正文第 9 章 §9.1「生成式推荐概述」: 为什么要先做语义离散化编码(Semantic Tokenization)。 正文要点: * 生成式推荐把推荐任务转化为序列生成任务: 给定用户历史行为序列、上下文与画像, 由模型直接生成用户未来最可能感兴趣的内容标识; * 但推荐系统的 Item 规模常达百万甚至亿级, 直接把 Item ID 当生成目标会导致词表 规模过大、训练与推理成本极高; * 因此主流做法是先把 Item 映射为一个或多个语义 ID: Item_A -> [s_1, s_2, s_3, s_4] 训练阶段把用户行为序列转成语义 ID 序列 [s_1, s_2, s_3] -> [s_4], 用 NTP 目标训练; * 推理阶段自回归生成 [s_1, s_2] -> [s_3] -> [s_4], 生成完整语义
