│ └── mtp_speculative_decoding.py MTP 多 Token 预测头 + 推测解码加速

对应正文第 9 章 §9.7「生成式推荐落地问题」中 MTP 与推测解码的推理加速。 正文公式: L_NTP = -log P(x_t | x_<t) L_MTP = -Σ_{i=0}^{K-1} log P(x_{t+i} | x_<t) 自回归推理: x_t -> x_{t+1} -> x_{t+2} (生成长度 T 需 T 次前向) MTP 推理: x_t -> (x_{t+1}, ..., x_{t+K}) (约 T/K 次前向) 物品由多个语义 Token 组成 item_i = (s_i^1, s_i^2, s_i^3), 传统需 s^1->s^2->s^3, 引入多 Token 预测头后 Decoder(h_t) 一次前向即可给出完整语义 ID。 本实现: 1. 共享 Backbone(单层 GRU)
