DCN-V2（第15章 §15.5.2） 把 DCN 的向量参数化改成矩阵： x_{l+1} = x_0 ⊙ (W_l x_l + b_l) + x_l 参数量从 O(Ld) 升到 O(Ld²)，表达能力更强；工业上常用低秩分解 W_l ≈ U_l V_l^T，U_l, V_l ∈ R^{d×r} 在效果与显存之间折中。 运行：python3 ch04_feature_interaction/dcn_v2.py
