Heterogeneous CF 召回 —— 异构行为协同过滤 / EHCF（第10章 §10.1.7） 核心思想：用户反馈是异构的（点击 -> 点赞 -> 收藏 -> 完播，漏斗逐级稀疏）。传统 CF 只用单一 行为建模，既浪费监督信号又高度依赖负采样。Heterogeneous CF 将多种行为统一建模，并通过 跨行为知识迁移（Knowledge Transfer）把高频行为学到的知识迁移给低频行为，从而在无需负 采样的情况下学到更准确的用户/物品 Embedding。 参考论文：Chen et al., "Efficient Heterogeneous Collaborative Filtering without Negative Sampling for Recommendation", AAAI 2020（EHCF） 一、HeteroItemC
