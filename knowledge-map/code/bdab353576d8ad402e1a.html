GAT 图注意力网络召回（第10章 §10.2.2 图网络召回 —— GAT召回） 核心思想： GCN 用固定的归一化系数 1/sqrt(d_i·d_j) 聚合邻居，GAT 则让模型自己学习 「每个邻居有多重要」：先给邻居打注意力分数，softmax 归一化后再加权聚合， 因此对度数分布不均、噪声边较多的推荐图更鲁棒，也更具可解释性。 核心公式（对应正文公式）： z_i = W h_i # 共享线性变换 e_ij = LeakyReLU( a^T [z_i ‖ z_j] ) # 未归一化注意力分数 α_ij = exp(e_ij) / Σ_{k∈N(i)} exp(e_ik) # 邻居维度 softmax
