Node2Vec 图嵌入召回（第10章 §10.2.1 「Node2Vec召回」） 核心思想： 在 DeepWalk 均匀随机游走的基础上引入「带偏置的二阶随机游走」（Biased Random Walk）。 游走时不仅看当前节点 v，还要看上一跳节点 t，对候选下一跳 x 赋非归一化权重： pi_vx = alpha_pq(t, x) * w_vx, P(x | v, t) = pi_vx / sum_{z in N(v)} pi_vz alpha_pq(t, x) = 1/p 若 d(t, x) = 0（x 就是上一跳 t，即「返回」） = 1 若 d(t, x) = 1（x 与 t 直接相邻，即「同一局部邻域」） = 1/q
