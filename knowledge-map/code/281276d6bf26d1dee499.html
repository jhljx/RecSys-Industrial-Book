统一价值模型(Unified Value Model)与平台整体价值。 对应正文第 8 章 §8.5 末尾「一些成熟的推荐系统还会构建统一价值模型,直接为每个 Item 计算综合价值分。该价值分同时考虑用户体验、商业收益、内容生态以及长期价值等多个目标」。 本实现做了什么: 1. 用 torch 搭一个共享底座 + 四个预估头的多任务价值模型,四个头分别对应正文列出的 四类目标:用户体验(观看时长)、商业收益(广告/打赏/GMV 折算收入)、内容生态 (新作者/新业务曝光健康度)、长期价值(次日回访倾向,近似 LTV); 2. 把四个预估头的输出按「兑换关系 + 平台战略权重」聚合成统一价值分 Value(item), 即统一价值模型的输出口径; 3. 以 Score_seq = sum_i gamma_i * Value(item_i) 为序列价值函数,对比四种打分
