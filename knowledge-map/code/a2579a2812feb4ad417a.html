Sentence-BERT（SBERT）模型（第10章 §10.3.3 基于预训练语义模型的向量召回） 核心思想： - 原生 BERT 做句子相似度要用 Cross-Encoder：把两句拼成 [CLS] A [SEP] B [SEP] 联合编码。 精度高，但一个 Query 要和 N 条候选各做一次前向，大规模检索复杂度 O(N) 次 Transformer 推理，两两匹配更是 O(N^2)，完全无法满足在线召回的延迟要求。 - SBERT 借鉴孪生网络（Siamese Network）改成 Bi-Encoder：两句分别过**共享参数**的同一个 编码器，各自 Pooling 得到定长句向量，再用余弦相似度比较： sim(u, v) = u^T v / (||u|| * ||v||) 于是候选文本可以离线编码建 ANN 索引，在线只需编码 Query 一次
