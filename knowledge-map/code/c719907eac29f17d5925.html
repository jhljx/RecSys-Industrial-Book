GDCN：门控交叉网络（第15章 §15.5.9） Gated Cross Layer： c_{l+1} = c_0 ⊙ (W^c_l c_l + b_l) ⊙ σ(W^g_l c_l) + c_l = Feature Crossing × Information Gate + 残差 - W^c 学交叉关系，W^g 学逐维门控，σ 把门控压到 (0,1) - 门控为 1 → 退化为 DCN-V2；门控学到的值可以直接看"哪一维交互被保留" 两种组合方式： GDCN-S（Stacked）：c_0 → GCN → c_L → DNN GDCN-P（Parallel）：c_0 → GCN 与 DNN 并行，输出拼接 运行：python3 ch04_feature_interaction/gdcn.py
