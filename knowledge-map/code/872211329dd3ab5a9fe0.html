GBDT + LR 精排模型（第12章 §12.3.2） 经典两阶段组合： 1. 训练 GBDT，将样本映射到叶节点 ID； 2. 将叶节点 ID 做 One-Hot 编码，作为 LR 的输入特征，再训练 LR。 正文说明（PDF 第 5–7 页）： - GBDT 通过多棵决策树逐步组合预测，F_T(x)=F_0(x)+η Σ h_t(x)； - 叶节点编码将 GBDT 自动学习到的非线性划分转为新特征，再由 LR 拟合； - 这体现"先提取特征、再建模"的思路，是深度学习前工业推荐的主流方案。 实现说明： - GBDT 用纯 Python + numpy-free 方式实现（不依赖 sklearn/xgboost）， 以便直接 python3 gbdt_lr.py 运行，无需额外依赖。 - LR 沿用本目录的 PyTorch 实现。 - 合成
