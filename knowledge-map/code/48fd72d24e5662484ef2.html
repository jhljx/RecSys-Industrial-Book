EGES 图嵌入召回（第10章 §10.2.1 「EGES召回」） 核心思想： DeepWalk / Node2Vec 只用图结构学习 Item ID Embedding，新物品缺少游走路径就学不到好的 表示。EGES（Enhanced Graph Embedding with Side Information）为每个物品额外引入 n 种 Side Information（品类、品牌、店铺……），每种 Side Info 维护独立的 Embedding 矩阵 W_s， 并用「每个物品私有且可学习」的权重矩阵 A ∈ R^{|V|x(n+1)} 做加权融合（s=0 表示 Item ID）： H_v = sum_{s=0..n} exp(a_v^s) * W_s(v) / sum_{s=0..n} exp(a_v^s), a_v^s = A_
