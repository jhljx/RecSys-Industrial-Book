E5 模型（第10章 §10.3.3 基于预训练语义模型的向量召回） 核心思想： - E5（EmbEddings from bidirEctional Encoder rEpresentations）用大规模**弱监督**文本对 （CCPairs：标题-正文、问题-回答、Query-点击文档等天然配对数据，无需人工标注）做对比预训练， 得到通用的文本向量模型。 - 关键设计是**非对称的指令前缀**：查询侧统一加 "query: "，文档侧统一加 "passage: "。 检索任务中 Query（短、口语化）与 Passage（长、书面化）形态差异很大，加前缀让**同一个共享 编码器**知道自己当前在编码哪一侧，从而把两类文本对齐到同一语义空间，而不必维护两个塔。 e_q = Encoder("query: " + q) e_p = Encod
