Online CF 召回 —— 实时协同过滤（第10章 §10.1.3） 核心思想： 传统 ItemCF / UserCF 依赖离线全量统计，相似度矩阵天级更新，无法响应热点。 Online CF 直接消费用户行为流（Kafka -> Flink -> Redis），行为到达后只更新 「受影响的 Item Pair」，并对历史共现分数做时间衰减，从而分钟级甚至秒级地 刷新 Item 之间的共现关系。 关键公式（与正文一致）： 1) 共现分数增量更新：Score(i, j) <- Decay(Score(i, j)) + w(j) 2) 行为权重： w(j) = Σ_k α_k · x_k(j) （点击1/长观看3/点赞5/关注8/分享10） 3) 时间衰减： Decay(x) = x · ex
