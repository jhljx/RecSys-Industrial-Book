双塔召回模型（第10章 §10.3.2） 核心思想： - 用户塔和物品塔各为一个 MLP，分别将用户特征和物品特征映射到同一语义空间 - 训练用 In-Batch 负采样（同 batch 内其他物品作为负样本） - 线上：提前计算物品 Embedding 存入向量数据库，查询用最近邻检索 本实现简化特征为 ID Embedding + MLP，使用 PyTorch autograd。
