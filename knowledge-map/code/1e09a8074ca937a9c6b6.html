MinHash：用随机排列 / 线性哈希估计 Jaccard 相似度（第18章 §18.3.1） 正文的核心性质： h_π(C) = min_{r∈C} π(r) P[h_π(A) = h_π(B)] = |A∩B| / |A∪B| = J(A,B) 用 L 个独立哈希得到签名，则 Ĵ = (1/L) Σ 1[h_i(A) = h_i(B)] → J(A,B) std(Ĵ) = sqrt(J(1−J)/L) 正文给了两种实现： 1) 随机排列（permutation）：最直观、完全符合定义，但需要保存 L 张 长度 d 的置换表，内存 O(L·d)； 2) 线性哈希：h(x) = (a·x + b) mod p，p 取大素数（2^31−1）。 每个哈希函数只存 (a, b) 两个整数，内存 O(L)，工程上等
