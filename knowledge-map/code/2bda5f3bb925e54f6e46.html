│ ├── simcse.py SimCSE：dropout 双视角对比学习（InfoNCE）

SimCSE 模型（第10章 §10.3.3 基于预训练语义模型的向量召回） 核心思想： - 原生 BERT 句向量存在「各向异性 / 表示退化」：所有句向量挤在向量空间的一个狭窄锥形区域里， 任意两句的余弦相似度都接近 1，几乎无法区分，直接拿来做向量召回效果很差。 - 无监督 SimCSE 的做法极其简洁：把**同一个句子**送入编码器两次，由于 Dropout 每次随机 置零的神经元不同，得到两个略有差异的向量 (h_i, h_i^+)，它们构成**正样本对**； 同一 Batch 内其他句子的表示则是负样本。Dropout 本身就是最小的数据增强。 - 训练目标为 InfoNCE（带温度系数 τ 的对比损失）： L_i = -log[ exp(sim(h_i, h_i^+)/τ) / Σ_{j=1..N} exp(sim(h_i, h_j^+)/τ) ]
