对应正文第 9 章 §9.2「生成式推荐架构」中生成式推荐与传统级联式架构的对比。 正文给出了两种工业部署方式: (1) 并行候选生成架构(Parallel Candidate Generation Architecture): 生成式推荐模块与传统召回并行产出候选, 最终汇合进入重排模块统一排序, 即 User -> Generative Recommendation -> Rerank; (2) 流量隔离架构(Traffic Isolation Architecture): 划分一定比例实验流量, 由生成式 模块直接产出 Item 集合再进入重排, 不再走"召回->粗排->精排"。 正文同时在 §9.8 讨论里强调: 级联架构的分层防护使单模块异常的影响可控, 而 One-Model 架构下模型异常会被放大到整条链路。 本实现用纯标准库做
