01 / GET STARTED

五分钟开始

在仓库根目录执行；需要 Python 3.10+ 与系统命令 pdftotext。

python3 tools/recsys_agent.py index
python3 tools/recsys_agent.py doctor
python3 tools/recsys_agent.py search "双塔召回的负采样偏差"
python3 tools/recsys_agent.py page --chapter 10 --page 60

doctor 应显示 index=ready。PDF 更新后重新执行 index；索引只写入本地被 Git 忽略的 .recsys-agent/。用 python3 tools/recsys_agent.py --help 查看所有参数。

03 / INSTALL & BOUNDARY

在 Agent 客户端使用

Canonical Skills 位于 .agents/skills/，可安装到目标项目，或直接在本仓库会话中用自然语言调用。

python3 tools/install_skills.py --client claude --target /path/to/project
python3 tools/install_skills.py --client agents --target /path/to/project

Skills 不会复制 PDF 或个人索引；课程状态仅写入本地被 Git 忽略的 .recsys-workspace/。公开站点没有全文检索，也不采集学习证据。
