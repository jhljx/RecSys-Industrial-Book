# 模型与 Embedding 版本错配案例

## 现象
发布后服务无报错，但向量召回率和最终消费指标下降；回滚模型未完全恢复。

## 匿名化证据
- 模型版本已切换，Embedding 缓存仍命中旧值；
- 缓存键不含 release 版本；
- ANN 索引和用户塔模型不属于同一产物集合。

## 根因与处理
各产物独立发布造成静默语义错配。引入 release manifest；请求、缓存键和索引均携带版本；兼容校验失败时拒绝切换并回滚整个 release。

## 验证
注入错配版本，确认发布门禁失败；灰度比较新旧 release 召回指标。

## 本书依据
《第十七章-推荐系统在线服务.pdf》，Embedding Server 与模型在线服务相关页面。

## 扩展说明
案例为匿名化教学材料，不包含私有架构或数据。
